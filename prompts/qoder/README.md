# Qoder 提示词（公开语料）

`public_corpus_prompt.txt` 来自公开语料，**不是**本次实验从产品中提取到的。Qoder 的工作台形态取不到二进制真值，正文原文在本次实验中 6 次探针全部被拒，因此这份文本只能作结构参考，不能当作判定依据。

## 本次实测拿到的部分

Qoder 的正文挡得住，工具面挡不住。实测取得的 26 个内置工具的名称、参数与默认值见：

- `data/qoder/原始输出_20261022.md`：完整输出
- `data/records/原始记录_按工具汇总.md` §1.1、§1.4–1.7：转录与后续四轮追问

把实测的工具定义与本地实现逐项比对，有 8 项一致、4 项不一致。四处不一致落在另一个版本的默认值与参数命名上（例如某个数值参数的默认值报的是旧实现的取值，某个重复替换参数的名称是本地已弃用的写法），编造不会恰好编出这种差异，因此反被当作「它读的是自己那份定义」的证据。具体比对表见报告 4.4。

## 注意

`public_corpus_prompt.txt` 未经本次实验核对，其版本、完整性都不确定；文中「被问到使用哪个模型时必须拒绝回答」一类条款，与实测中 Qoder 的行为一致，但一致不等于同源。版权归 Qoder 所有，仅作研究引用。
