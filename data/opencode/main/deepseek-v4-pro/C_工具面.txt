下面是我当前可用的全部工具，按类别逐条列出名称、参数和调用条件。

## 一、文件与代码操作

### 1. `read`
- **参数**：`path`（文件或目录路径）、`offset`（起始行，可选）、`limit`（最大行数，可选）
- **调用条件**：需要查看文本文件内容、图片、PDF，或列出一个目录的内容时使用。

### 2. `write`
- **参数**：`path`（文件路径）、`content`（要写入的内容）
- **调用条件**：需要创建新文件或完全覆盖已有文件内容时使用；缺少的父目录会自动创建。

### 3. `edit`
- **参数**：`path`（文件路径）、`oldString`（要替换的原文本）、`newString`（替换后的新文本）、`replaceAll`（是否替换所有匹配，可选，默认 false）
- **调用条件**：需要对已有文件做局部、精确的文本修改时使用；`oldString` 必须能唯一定位，或配合 `replaceAll: true` 全部替换。

### 4. `glob`
- **参数**：`pattern`（glob 匹配模式，如 `**/*.ts`）、`path`（搜索目录，可选）、`hidden`（是否含隐藏文件，可选）、`limit`（最大返回数，可选）
- **调用条件**：需要按文件名模式查找文件位置时使用。

### 5. `grep`
- **参数**：`pattern`（正则或字面文本）、`path`（搜索路径，可选）、`include`（文件过滤 glob，可选）、`literal`（是否按字面文本匹配，可选）、`caseSensitive`（是否区分大小写，可选）、`limit`（最大返回数，可选）
- **调用条件**：需要在文件内容里搜索特定代码、符号或文本片段，并在大文件中定位时使用。

## 二、命令执行

### 6. `shell`
- **参数**：`command`（要执行的 shell 命令，Windows 用 PowerShell）、`workdir`（工作目录，可选）、`timeout`（超时毫秒数，可选）、`background`（是否后台运行，可选）
- **调用条件**：当没有专门工具能完成某个任务时，回退到 shell 执行命令（如构建、运行脚本）；长时间运行的服务用 `background: true`。

### 7. `execute`
- **参数**：`code`（在受限 Code Mode 运行时里执行的 JavaScript 代码）
- **调用条件**：需要编排工具调用、发起 HTTP 请求（`fetch`）或组合结果时使用；此运行时里只能调用目录中 `tools.*` 列出的工具，不能直接访问文件系统、导入模块或使用定时器。

## 三、信息检索

### 8. `websearch`
- **参数**：`query`（搜索查询词）
- **调用条件**：需要获取超出知识截止日期的最新信息或时事时使用。

### 9. `webfetch`
- **参数**：`url`（HTTP/HTTPS 地址）、`format`（返回格式 text/markdown/html，可选）、`timeout`（超时秒数，可选，最大 120）
- **调用条件**：需要抓取某个网页内容（只读）时使用。

## 四、交互与协作

### 10. `question`
- **参数**：`questions`（问题数组，每项含 `question`、`header`、`options`、`multiple`）
- **调用条件**：执行过程中需要向用户澄清模糊需求、收集偏好、或在实现方案上让用户做选择时使用。

### 11. `skill`
- **参数**：`id`（要加载的技能 ID，必须匹配可用技能或用户显式提及的技能）
- **调用条件**：当任务匹配某个技能的描述时，加载该技能获取专门指令与资源（例如 arkcli 相关各技能、OpenCode、report 等）。

### 12. `subagent`
- **参数**：`agent`（子代理类型）、`description`（简短任务描述）、`prompt`（任务内容）、`sessionID`（继续某个历史子代理会话，可选）、`background`（是否后台运行，可选）、`model`（除非用户明确要求否则不要设置）
- **调用条件**：需要把复杂、独立的子任务交给专门的子代理（如 `explore` 探索代码库、`general` 处理多步任务）并行/分离处理时使用。

## 五、OpenCode 自身管理（需通过 `execute` 在 `tools.opencode.*` 下调用）

### 13. `opencode.list_mcp_resources`
- **参数**：`server`（MCP 服务器名，可选）
- **调用条件**：列出 MCP 服务器暴露的文档、记录等资源，或用户提到某个非本地文件的 MCP 资源时使用。

### 14. `opencode.read_mcp_resource`
- **参数**：`server`、`uri`
- **调用条件**：读取指定的 MCP 资源内容（不适用于本地文件）时使用。

### 15. `opencode.models`
- **参数**：`query`、`provider`、`all`、`limit`、`offset`
- **调用条件**：搜索可用模型，把用户提到的模型名转成精确引用（如 `providerID/modelID`）时使用。

### 16. `opencode.session_move`
- **参数**：`sessionID`（可选，缺省为当前会话）、`directory`（目标目录）
- **调用条件**：将当前或指定会话移动到其他目录时使用。

### 17. `opencode.session_rename`
- **参数**：`sessionID`（可选）、`title`（新标题）
- **调用条件**：重命名当前会话或指定会话时使用。

### 18. `opencode.worktree_create`
- **参数**：`name`（工作树名称）
- **调用条件**：创建命名的工作树并返回其目录时使用。

### 19. `opencode.worktree_list`
- **参数**：无
- **调用条件**：列出仓库的工作树时使用。

### 20. `opencode.worktree_remove`
- **参数**：`directory`（要删除的工作树绝对路径）、`force`（是否强制丢弃修改，可选）
- **调用条件**：移除工作树时使用；`force` 仅在用户确认强制删除时才设置。
